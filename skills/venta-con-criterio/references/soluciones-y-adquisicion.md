# Soluciones y adquisicion

## Catalogo de hipotesis

El material enumera automatizaciones frecuentes. Usalas para generar hipotesis despues de entender el problema:

| Situacion | Solucion posible | Resultado a investigar |
| --- | --- | --- |
| Consultas sin respuesta rapida | Respuesta inicial y clasificacion | Menos oportunidades enfriadas |
| Prospectos sin continuidad | Seguimiento automatico | Mas conversaciones retomadas |
| Coordinacion manual | Agendamiento | Menos intercambio operativo |
| Ausencias a citas | Recordatorios | Menos huecos y tiempo perdido |
| Altas desordenadas | Onboarding | Menos tareas manuales y mejor continuidad |
| Informacion dispersa | Reportes automaticos | Menos tiempo de consolidacion |
| Carritos abandonados | Recuperacion de carrito | Ventas potencialmente recuperadas |
| Contactos inactivos | Reactivacion | Nuevas conversaciones desde una base existente |
| Consultas repetitivas | Respuestas automatizadas | Equipo liberado para tareas de mayor valor |
| Posventa irregular | Seguimiento, estado y resenas | Mejor experiencia y recompra potencial |

Fuente: `04-que-automatizaciones-vender` (`01:34–17:02`).

No traslades porcentajes, estudios o resultados mencionados verbalmente sin verificar fuente, vigencia y aplicabilidad. La reactivacion de contactos y los mensajes automaticos dependen del consentimiento, la privacidad y las reglas del canal.

## Demo funcional

La demo sirve para volver visible una solucion. El recorrido sugerido es:

1. definir un problema especifico;
2. construir un MVP que muestre el flujo principal;
3. explicar primero el resultado;
4. mostrar despues las funciones necesarias;
5. hacer una propuesta concreta o acordar el siguiente paso.

Una demo demuestra funcionamiento, no ROI ni demanda. Evita presentarla como caso real si utiliza datos hipoteticos.

Fuente: `07-como-conseguir-clientes` (`20:48–22:25`).

## Secuencia de adquisicion extraida

El material propone avanzar por etapas:

### 1. Red y conversaciones

- empezar con contactos existentes;
- pedir presentaciones o referidos;
- hablar con negocios del segmento;
- aprender como describen sus problemas.

### 2. Oferta directa con demo

- elegir un problema y un segmento;
- preparar un MVP funcional;
- presentar beneficio, funcionamiento y oferta.

### 3. Documentacion y contenido

- registrar proyectos, procesos, resultados y detras de escena;
- explicar decisiones y diferencias de implementacion;
- crear contenido para problemas especificos;
- evitar inventar experiencia o resultados.

### 4. Escala paga

El material ubica los anuncios despues de tener una oferta probada, conversaciones, casos y contenido suficiente.

Fuente: `07-como-conseguir-clientes` (`01:02–12:59`, `31:02–36:45`).

## Limites de uso

Las transcripciones recomiendan tacticas intensivas de contacto presencial y seguimiento. Los documentos de analisis advierten que no deben convertirse en insistencia indefinida, contacto fuera de contexto, grabacion sin permiso o mensajeria masiva sin consentimiento. Trata la eleccion del canal y la frecuencia como decisiones contextuales.
