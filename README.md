# Auditoria de prospectos

Sistema local de skills y artefactos para auditar sitios publicos con evidencia y convertir los hallazgos en conversaciones comerciales sin inventar impacto.

## Flujo

1. `auditoria-web-prospectos` recorre la superficie publica, reproduce hallazgos y produce el informe.
2. `handoff-comercial.md` conserva hechos, hipotesis, vacios y preguntas.
3. `venta-con-criterio` usa ese handoff para preparar descubrimiento, dimensionar valor y, solo cuando existen datos suficientes, construir una oferta.

## Estructura

- `skills/auditoria-web-prospectos/`: auditoria externa basada en evidencia.
- `skills/venta-con-criterio/`: copia local y adaptada; la skill fuente instalada permanece fuera de este repositorio.
- `skills/shared/auditoria-a-venta.md`: contrato entre ambas etapas.
- `auditorias/`: resultados por prospecto y fecha.

La auditoria no autoriza contacto, publicacion, pruebas activas de seguridad ni acciones irreversibles sobre sistemas del prospecto.
